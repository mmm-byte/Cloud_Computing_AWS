# Module 7: Cloud Security (AWS Security as a Service)

**Lab:** [Lab 7: Secure Architectures](../../labs/lab-07-secure-architectures/)

## What this module covers
- Security in the cloud: the shared responsibility model, the Cloud Security Alliance guidance and the top threats to cloud computing.
- The six attack surfaces (research topic).
- AWS security services and designing secure architectures.
- Privacy law and international agreements (discussion).

## Key concepts
| Concept | One-line summary |
|---|---|
| Shared responsibility | AWS secures the cloud; you secure what you put in it |
| Least privilege and MFA | Foundation of identity security (see [Module 1](../01-iam/)) |
| Network controls | Security groups, NACLs and private subnets (see [Module 4](../04-networking-vpc-route53-cloudfront/)) |
| Encryption | Protect data at rest and in transit |
| Logging and detection | CloudTrail and Config feed audits and alerts (see [Module 6](../06-monitoring-sns-sqs/)) |
