# Module 11: Architectural Kata Project

**Lab:** none (team project)

## What this module covers
A capstone in two phases:
1. **Discussion phase (report):** design an architecture for an assigned scenario and document the decisions and trade-offs.
2. **Presentation phase:** present and defend the design.

## How to document your kata here
Add your report and slides under this folder, for example:

```
modules/11-architectural-kata/
  report.pdf
  slides.pdf
  diagrams/
```

Then link them from this page and summarize the scenario, the key architectural decisions (compute, storage, networking, security, scaling) and what you would change.
