# Module 10: Cloud Automation (CloudFormation and Infrastructure as Code)

**Lab:** none (research report and quiz only)

## What this module covers
- Describing infrastructure as code so it is repeatable, reviewable and version-controlled.
- **AWS CloudFormation:** templates, stacks, parameters and change sets.
- Amazon privacy policies (research topic).

## Key concepts
| Concept | One-line summary |
|---|---|
| Template | JSON/YAML description of resources |
| Stack | A deployed instance of a template, created, updated and deleted as a unit |
| Change set | Preview of what an update will change |
| Drift | Difference between the template and what is actually deployed |
