# Module 9: Big Data, Data Streaming and the Mobile Cloud

**Lab:** none (research report and quiz only)

## What this module covers
- Big data on AWS: **Redshift** (data warehouse), **EMR** (managed Hadoop/Spark) and **Kinesis** (real-time streaming).
- Stream processing concepts and Apache Kafka (research topic).

## Key concepts
| Concept | One-line summary |
|---|---|
| Data warehouse | Columnar store optimized for analytical queries (Redshift) |
| EMR | Managed clusters for Spark/Hadoop batch processing |
| Kinesis | Ingest and process streaming data in real time |
| Kafka | Open-source distributed log for event streaming |

## Course materials
- Slides: AWS Big Data
- Research and report: Apache Kafka
- Quiz: Big data and data streaming
